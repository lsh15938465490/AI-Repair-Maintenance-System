# PCB 维修 Skill 细则

与 `src/skills/pcb-repair.md`、仓库知识库原文规则对应，供实现识别逻辑时查阅。

## 六大子技能

### 1. 外观视觉故障识别

解析正面实拍图、可选反面实拍图（及可选原理图），识别板体、元器件、线路、焊点、接口显性故障。

- 板体：弯曲、开裂、烧蚀、发黑、分层、铜箔脱落、过孔断裂
- 元器件：电容鼓包漏液、功率器件击穿发黑、电阻熔断开裂、二极管炸裂、芯片烧蚀、引脚氧化
- 焊点：虚焊、假焊、脱焊、连锡短路、锡珠、焊盘空洞
- 线路接口：铜箔断线、腐蚀、接口松动氧化、针脚变形

输出：点位 + 等级（显性致命 / 隐性潜在）+ 初步原因。同时完成本项目的丝印型号提取；仅在有反面图时做正反面对齐判断。

### 2. 故障现象匹配与分级定位

内置 5 大故障推理模型（固定匹配）：

| 现象 | 模型 | 高发点 |
|------|------|--------|
| 无反应不开机 | 电源回路 | 保险、整流桥、电源芯片、主电容、电源短路 |
| 间歇性重启、时好时坏 | 软性故障 | 电容老化、虚焊、过孔暗断、接口接触不良 |
| 上电烧保险、炸机 | 功率器件击穿 | MOS/IGBT/整流桥短路、负载短路 |
| 开机正常、功能异常 | 信号与主控 | 晶振、通讯线路、芯片虚焊、程序异常 |
| 带载发热、跳闸保护 | 功率驱动 | 散热不良、采样电阻变值、驱动波形畸变 |

无用户文字描述时，根据图像与知识库选择最接近的模型，并在 `faultModel` 写明。

### 3. 标准化 8 步维修

安全预处理 → 目视复检 → 静态阻值检测 → 故障分区定位 → 动态电压检测 → 波形信号检测 → 元件修复更换 → 验证老化测试

按故障类型加减重点：短路强化静态；功能异常强化信号；间歇性强化虚焊与电容。

### 4. 元器件判定

外观异常直接判定故障；无外观异常则结合电路参数、工况判定隐性老化/变值/失效。杜绝无依据的整板更换建议。

### 5. 风险预警

见 SKILL.md 安全拦截。`riskWarnings` 必须列出本次禁止操作。

### 6. 验证与复盘

静态阻值复测 → 空载电压测试 → 带载功能测试 → 短时老化测试 → 隐患排查复盘。写入 `verification`。

## 异常兜底

- 图像无明显故障但可推断设备异常：按隐性故障，优先电容老化、虚焊、过孔暗断、信号异常
- 信息不足：在 `alignment.detail` 或故障原因中列出需补充的【是否开机、是否发热、是否报错、是否烧保险】，仍给出由易到难的排查，不要中断 JSON
- 疑难故障：先排除高发简单故障，再深入信号与芯片
