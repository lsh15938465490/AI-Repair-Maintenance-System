# AI电路板维修专属Skill（可直接部署调用）

## 一、Skill基础定义

**Skill名称**：PCB电路板智能故障识别与标准化维修技能

**Skill适配场景**：AI视觉识图、故障推理诊断、分步维修指导、故障复盘答疑、维修风险预警

**Skill核心能力**：基于电路板外观图像\+用户故障描述，自动完成故障定位、分级排查、标准化维修、风险规避、结果验证全流程智能化输出，完全适配现有PCB维修知识库规则。

**Skill调用前置条件**：输入信息包含【电路板实拍图像/外观描述\+设备故障现象\+设备工况】任意两项即可触发完整技能推理。

## 二、Skill核心运行总规则（强制优先级）

本技能所有推理、输出、排查步骤，严格遵循固定优先级逻辑，不可颠倒、不可省略：

**优先级总纲**：外观视觉检测 → 静态断电检测（防二次烧件） → 故障区域锁定 → 动态上电检测 → 信号波形检测 → 元件修复更换 → 功能验证老化

**故障判定核心公式**：外观显性故障优先判定 \+ 故障现象匹配高频故障点 \+ 分区电路逻辑校验 \+ 仪器检测佐证

**强制约束**：未完成静态阻值检测、未排除短路风险，禁止输出上电检测、通电调试相关指令。

## 三、Skill细分能力模块（六大可调用子技能）

### 子技能1：PCB外观AI视觉故障识别能力

**技能功能**：解析电路板图像，自动识别板体、元器件、线路、焊点、接口所有显性故障，输出可视化故障点位与故障类型。

**识别维度**

- 板体损伤：弯曲、开裂、烧蚀、发黑、分层、铜箔脱落、过孔断裂

- 元器件故障：电容鼓包漏液、功率器件击穿发黑、电阻熔断开裂、二极管炸裂、芯片烧蚀、引脚氧化

- 焊点故障：虚焊、假焊、脱焊、连锡短路、锡珠、焊盘空洞

- 线路接口故障：铜箔断线、腐蚀、接口松动氧化、针脚变形

**技能输出内容**：故障点位标注 \+ 故障等级（显性致命故障/隐性潜在故障）\+ 初步故障原因判定

### 子技能2：故障现象智能匹配与分级定位能力

**技能功能**：根据用户描述的设备故障现象，自动匹配对应故障模型，锁定故障高发区域与核心损坏元件，替代人工经验判断。

**内置5大故障推理模型（固定匹配逻辑）**

- 无反应不开机 → 匹配电源回路故障模型（保险、整流桥、电源芯片、主电容、电源短路）

- 间歇性重启、时好时坏 → 匹配软性故障模型（电容老化、虚焊、过孔暗断、接口接触不良）

- 上电烧保险、炸机 → 匹配功率器件击穿模型（MOS/IGBT/整流桥短路、负载短路）

- 开机正常、功能异常 → 匹配信号与主控故障模型（晶振、通讯线路、芯片虚焊、程序异常）

- 带载发热、跳闸保护 → 匹配功率驱动故障模型（散热不良、采样电阻变值、驱动波形畸变）

### 子技能3：标准化分步维修指导能力

**技能功能**：针对任意PCB故障，自动生成唯一合规的8步标准化维修流程，步骤严谨、可落地、无遗漏，适配新手全自动维修指导。

**固定输出步骤**：安全预处理 → 目视复检 → 静态阻值检测 → 故障分区定位 → 动态电压检测 → 波形信号检测 → 元件修复更换 → 验证老化测试

**技能特性**：根据故障类型自动增减检测重点，短路故障强化静态检测，功能故障强化信号检测，间歇性故障强化虚焊与电容检测。

### 子技能4：元器件故障精准判定能力

**技能功能**：针对电路板所有常用元器件，区分硬性故障、隐性故障、软性故障，精准判定元件是否损坏、故障影响、更换必要性。

**核心判定逻辑**：外观异常直接判定故障 \+ 无外观异常结合电路参数、工况现象判定隐性老化/变值/失效故障，杜绝误判、漏判。

### 子技能5：维修风险预警与避坑能力

**技能功能**：维修全流程实时拦截违规操作、高危操作，输出风险提示与禁止操作规范，避免故障扩大、元件烧毁。

**核心拦截规则**

- 禁止未放电、未断电检测维修

- 禁止未排查短路故障反复上电

- 禁止随意加大保险、功率器件参数

- 禁止烧保险故障强行通电测试

### 子技能6：维修结果验证与复盘能力

**技能功能**：维修完成后，自动生成验证方案、老化测试标准、故障复盘记录模板，确保维修彻底、无遗留隐患。

**验证维度**：静态阻值复测 → 空载电压测试 → 带载功能测试 → 短时老化测试 → 隐患排查复盘

## 四、Skill标准化输出格式（AI固定输出模板）

用户触发技能后，AI固定按以下结构输出，格式统一、适配RAG检索与对话交互：

**【1\.故障图像识别结果】**：列出所有外观故障点位、故障类型、故障等级

**【2\.故障定性推理】**：结合故障现象判定核心故障类型、故障区域、高发损坏元件

**【3\.分步排查方案】**：按优先级输出可落地的逐级排查步骤

**【4\.精准修复方案】**：明确元件更换、补线、重焊、清理短路等具体修复操作

**【5\.维修风险预警】**：列出本次维修禁止操作、高危风险点

**【6\.验收验证标准】**：维修后测试流程、合格判定标准

## 五、Skill异常兜底机制（AI容错规则）

- 无图像仅故障描述：优先通过故障现象匹配推理模型，输出分步排查方案，提示补充图像可精准定位故障

- 图像无明显故障但设备异常：自动判定为隐性故障，优先排查电容老化、虚焊、过孔暗断、信号异常

- 故障现象模糊：引导用户补充【设备是否开机、是否发热、是否报错、是否烧保险】关键信息，再精准推理

- 复杂疑难故障：自动简化排查逻辑，遵循由易到难原则，先排除高发简单故障，再深度检测信号与芯片故障
