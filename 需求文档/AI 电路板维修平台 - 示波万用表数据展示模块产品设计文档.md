# AI 电路板维修平台 - 示波万用表数据展示模块产品设计文档

> 
> 角色：10 年业务产品经理，面向电路板维修 AI 系统，新增「外接示波万用表数据可视化模块」，支持接收外部万用表设备上报数据流，页面模拟示波万用表整机 UI，包含波形渲染、档位图标状态闪烁、测量数值、设备状态，适配电路板维修业务场景。
> 文档版本：V1.0

## 1 模块概述

### 1.1 业务背景

在 AI 电路板维修场景中，用户外接**示波万用表（示波表）**，设备实时回传测量数据，需要在系统 Web 页面复现实设备操作面板效果。

1. 支持波形图形展示（电压波形、时序波形）；
2. 非波形类档位（蜂鸣通断档、二极管档、电阻档、电流档）提供图标、状态闪烁、数值展示，**不绘制波形**；
3. 接收外部示波万用表标准上报数据流；
4. UI 贴近实体示波万用表操作面板，适配维修人员操作习惯，和电路板元器件标注模块协同工作。

### 1.2 模块目标

1. 对接外接示波万用表设备数据接口，接收设备上传实时测量数据；
2. Web 端还原示波万用表完整面板 UI：数值显示区、波形画布区、档位状态图标区、设备状态指示灯；
3. 区分两类测量模式：
   - 波形模式：AC 电压、DC 电压、示波器模式 → 渲染波形图；
   - 普通档位模式：蜂鸣档、二极管档、电阻、电容、电流档 → **无波形渲染，状态图标闪烁 + 数值展示**；
4. 状态反馈：例如蜂鸣档导通时，蜂鸣图标闪烁；
5. 可和本系统原有电路板元器件标注模块联动，维修时一边看电路板标注，一边读取万用表实时测量值。

### 1.3 依赖模块

1. 前端：Vue/React + Canvas（波形渲染）；
2. 数据接收层：接收外部示波万用表上报数据（WebSocket 实时流为主，兼容 HTTP 轮询）；
3. 协同模块：电路板元器件自动标注模块（YOLO+VLM 元器件标注）；
4. 后端：数据接收、数据校验、数据转发。

## 2 外接示波万用表设备数据协议参考（市面通用示波万用表）

> 
> 市面上主流示波万用表，一般通过 USB、蓝牙转 WebSocket 向上位机推送 JSON 数据流，本模块定义接收数据格式。

### 2.1 通信方式

1. **优先：WebSocket 长连接**，设备持续推送实时测量数据（高频，10‑50Hz）；
2. 备选：HTTP 轮询，兼容老旧设备；
3. 设备连接状态：已连接 / 断开 / 数据异常。

### 2.2 设备上报 JSON 数据结构

```
{
  "device_status":"online", //online/offline/error
  "gear_type":"beep", //档位：dcv/acv/beep/diode/resistance/cap/current_ac/current_dc/osc
  "measure_value": 0.001, //测量读数
  "measure_unit":"Ω", //单位 V A Ω F
  "is_trigger":true, //特殊状态触发：蜂鸣导通true/false，二极管导通true/false
  "battery":85, //设备电池百分比
  "wave_enable":true, //true=需要渲染波形；false=不渲染波形（蜂鸣/电阻档等）
  "wave_data":[1.2,1.1,1.3,1.0], //波形采样点数组，wave_enable=true生效
  "wave_sample_rate":10000, //采样率 S/s
  "wave_v_div":"1V/div", //电压每格
  "wave_t_div":"1ms/div", //时间每格
  "error_code":0
}
```

表格

| 字段 | 说明 |
| --- | --- |
| gear_type | 档位枚举：`dcv`直流电压、`acv`交流电压、`osc`示波器模式、`beep`蜂鸣通断档、`diode`二极管档、`resistance`电阻档、`cap`电容档、`current_ac`交流电流、`current_dc`直流电流 |
| wave_enable | true：开启波形渲染；false：关闭波形画布，仅展示图标、数值、闪烁状态（蜂鸣档、电阻档） |
| is_trigger | 布尔值，用于触发图标闪烁：蜂鸣档导通、二极管导通时置 true，前端控制图标闪烁动画 |
| wave_data | 波形采样点数组，仅波形模式下携带 |

> 
> 业务规则：
> 
> 
> 1. `gear_type=beep`蜂鸣档：`wave_enable=false`，不渲染波形；`is_trigger=true`代表导通，蜂鸣图标闪烁。
> 2. `gear_type=resistance`电阻档：`wave_enable=false`，只展示电阻读数，无图标闪烁。
> 3. `gear_type=osc`示波器模式：`wave_enable=true`，画布渲染波形。

## 3 页面 UI 详细规划（Web 页面布局）

页面整体分为 4 大区域，整体模仿实体示波万用表面板，页面可以和电路板标注视图左右分栏布局。

> 
> 布局：【左侧：电路板元器件标注视图】｜【右侧：示波万用表模块面板】

### 区域 A：设备连接状态栏（顶部）

1. 设备连接状态指示灯：绿色 = 在线；红色 = 断开；黄色 = 数据异常；
2. 设备编号、设备电池电量展示；
3. 连接按钮、断开按钮；
4. 错误提示栏，展示设备 error_code 对应的故障文字。

### 区域 B：档位与大数值显示区（模拟万用表数码管大屏）

1. 当前档位文字大字体展示：`蜂鸣通断档 / DC电压 / 二极管档 / 示波器模式`；
2. **超大号测量读数 + 单位**，类似万用表数码管效果；
3. 超量程提示：当设备上报超量程，显示`OL`。

### 区域 C：功能图标状态区（核心：闪烁图标）

> 
> 此区域放置各个档位对应的状态图标，当`is_trigger=true`，图标执行闪烁动画（CSS 动画，0.5s 闪烁一次）。
> 图标清单：

1. 📢蜂鸣档图标：导通时闪烁；断开静态。
2. ➡️二极管图标：二极管正向导通闪烁。
3. ⚡过压告警图标：超量程时闪烁告警。

> 
> 当`wave_enable=false`（蜂鸣、电阻、二极管档位），波形画布区域隐藏，本图标区域突出展示。

### 区域 D：波形画布显示区（Canvas 绘制）

1. 仅当`wave_enable=true`的时候画布显示；`wave_enable=false`，画布隐藏，占位空白；
2. 画布内置示波器网格背景（方格坐标）；
3. 渲染`wave_data`采样点波形曲线；
4. 面板显示参数：`V/div`垂直档位、`T/div`时基、采样率；
5. 支持基础操作：波形暂停、继续。

### 完整页面排版从上至下

```
┌─────────────────────────────────────┐
│ 设备状态｜电池电量｜连接/断开按钮      │  A区
├─────────────────────────────────────┤
│ 【档位名称】                          │
│ 【超大字体测量数值 单位】 OL超量程提示 │  B区
├─────────────────────────────────────┤
│ 📢蜂鸣图标  ➡二极管图标  ⚡告警图标   │  C区（is_trigger触发闪烁动画）
├─────────────────────────────────────┤
│                                     │
│     Canvas波形网格画布                │  D区（wave_enable=true显示，否则隐藏）
│ V/div:1V/div    T/div:1ms/div        │
│                                     │
└─────────────────────────────────────┘
```

##4 核心功能详细需求
###4.1 数据接收逻辑

1. 前端建立 WebSocket 连接，监听设备推送 JSON 数据流；
2. 做数据校验，字段缺失、异常值做容错，不造成页面崩溃；
3. 设备离线时，页面状态切换离线，数值冻结；
4. 数据流频率高，前端做节流，避免页面渲染卡顿。

###4.2 档位分支渲染逻辑（核心）

1. **波形类档位（osc/acv/dcv）**
   - `wave_enable=true`；
   - 显示 Canvas 波形画布，渲染 wave_data 波形；
   - B 区展示测量数值；
   - C 区图标静态，不闪烁。
2. **无波形档位（beep /diode/resistance /cap）**
   - `wave_enable=false`，**隐藏波形 Canvas 画布**；
   - B 区展示测量读数；
   - 根据`is_trigger`布尔值控制对应图标 CSS 闪烁动画；
   - 示例：蜂鸣档，测量导通 → `is_trigger=true`，蜂鸣图标闪烁；测量断开，图标停止闪烁。

> 
> 闪烁动画实现：CSS keyframes，透明度 0%‑100% 循环，周期 500ms。

###4.3 特殊业务逻辑

1. 超量程：设备上报测量溢出，页面显示`OL`；过压告警图标闪烁；
2. 蜂鸣档：仅导通状态图标闪烁；
3. 设备断线：所有数值冻结，状态变红，图标停止闪烁；
4. 波形画布：仅收到 wave_data 数组才绘制；无数据画布空白。

###4.4 和原有电路板标注模块联动

1. 页面支持左右分栏：左侧电路板标注图，右侧示波万用表面板；
2. 维修场景：用户选中电路板元器件，同时查看万用表实时测量读数。

##5 异常处理清单

1. WebSocket 断开：页面提示设备断开，UI 状态切换离线；
2. 设备上报数据字段缺失：跳过本次渲染，控制台打印日志，页面不报错；
3. wave_data 为空，但是 wave_enable=true：画布展示 “无波形数据” 文字；
4. 高频数据流渲染卡顿：前端节流，限制最大渲染帧率 20 次每秒。
